Átírtam a style.css fájlt: az egész oldal (body) 80% széles és középre igazított. A nav, a main és a footer így ugyanakkora szélességű. Ezt a böngészőben nem néztem meg.

A változtatások:

body {
  display: flex;
  flex-direction: column;
  width: 80%;
  min-height: 100vh;
  margin: 0 auto;
  /* ...a többi változatlan */
}

main {
  display: flex;
  flex-direction: column;
  flex: 1;
  gap: 32px;
  width: 100%;
  margin: 32px 0;
}
A main korábban maga volt 80%, ezt levettem róla, mert most a body adja a szélességet. A nav alsó vonala is csak ilyen széles. A footer többi része változatlan.
